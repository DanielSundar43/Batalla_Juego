# Sistema de Batalla - Parcial II

## Descripción
Este proyecto implementa un sistema de batalla entre criaturas usando programación orientada a objetos en Java.

Se aplican conceptos como:
- Herencia
- Polimorfismo
- Interfaces
- Composición

## Estructura del proyecto

- Criatura: clase abstracta base  
- Dragon, Mago, Guerrero: clases concretas  
- Volador, Magico: interfaces  
- Arma: clase para daño adicional  
- Batalla: lógica de combate  
- Main: ejecución del programa  

---

## Funcionalidades

- Simulación de combate entre criaturas  
- Uso de armas para aumentar daño  
- Aplicación de polimorfismo en ataques  
- Verificación de estado de vida  

---

## Ejecución

1. Ejecutar la clase Main
2. Observar el resultado de la batalla en consola
